# DexCav

**DexCav: Dexterous exCavation of Semi-Buried Objects with Multimodal Sensorimotor Policy**

[Project Website](https://prevalenter.github.io/dexexcavation.github.io/) | [Video](https://www.youtube.com/watch?v=ce2kmOa-XX8) | [Code (coming soon)](https://prevalenter.github.io/dexexcavation.github.io/) | [Dataset](https://drive.google.com/drive/folders/1v-tm5jcuH-26QcOveGWhI5ZOK7TAZ9SG?usp=drive_link)

## Overview

DexCav is a multimodal sensorimotor policy for dexterous excavation of semi-buried objects. It uses dual-view RGB images, arm-hand proprioception, and tactile measurements to coordinate arm-hand motion in changing granular media. The accompanying synchronized teleoperation dataset contains 400 demonstrations across eight object types recorded on a common 15 Hz timeline.

## Repository

This repository hosts the DexCav project website. The research code will be released after the review period.

## Environment Configuration

This is a static project-website repository. The root contains no Python
requirements, Conda environment file, Node package manifest, or pinned build
toolchain. Editing the HTML and static assets therefore does not require the
DexCav policy environment. If a local preview server is used, record its
tool and version separately; no runtime environment is currently claimed by
this repository.
